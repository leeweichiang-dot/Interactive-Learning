Counting in Binary

Two digits are enough

We normally count in decimal, using ten digits (0–9). Computers store everything as tiny switches that are either off or on, so they count in binary, using just two digits: 0 and 1.

Each binary digit is called a bit.

Every place is worth double

In decimal, each place is worth ten times the one to its right: ones, tens, hundreds. In binary, each place is worth two times the one to its right:

128643216 8421

To read a binary number, add up the places that hold a 1. For example, 101 is 4 + 1 = 5.

Recap

  • Binary uses only the digits 0 and 1; each one is a bit.
  • Each place is worth double the place to its right: 1, 2, 4, 8, 16…
  • Add the places holding a 1 to get the decimal value.
  • Eight bits can make any number from 0 to 255.
